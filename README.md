# 컬쳐랜드 쓸곳찾기

> 어디서 쓸 수 있는지 묻고, 그 자리에서 쓰는 법까지.

Y-AI 메이커톤 2026 **컬쳐랜드 사전 미션** 제출용 클릭형 시제품입니다.
사용처 확인(이름·카테고리·자연어 질문 → 온라인/매장별 사용 가능 여부)과 상품권 사용 안내(충전·바코드·전환 순서)를 **하나의 이용 흐름**으로 잇는 컬쳐랜드 **앱** 기능을 제안합니다.

- **클릭형 시제품**: https://usedupnote.github.io/cultureland-finder/
- **설명 자료(PDF, 5쪽)**: [docs/explain.pdf](docs/explain.pdf)

PC에서 열면 왼쪽 패널의 **시나리오 A~E·M** 버튼으로 바로 시연할 수 있습니다. 휴대폰에서는 앱 화면이 전체로 열리고, 오른쪽 아래 **시연 시나리오** 버튼을 쓰면 됩니다.

> 컬쳐랜드 공식 서비스가 아닌 대회 제출용 시제품입니다. 결제·충전·계정은 모두 시연용 가상 데이터이며, 브랜드 에셋은 미션 제공 범위에서만 사용했습니다.

## 시연 시나리오

| | 질문 | 보여주는 것 |
|---|---|---|
| A | 편의점에서 컬쳐랜드상품권 써도 돼? | 매장 사용 가능 → 충전 없이 문자 바코드로 결제하는 3단계 안내 → 시연용 상품권 문자 → 완료 |
| B | 쿠팡에서 쓸 수 있어? | 결제창에서는 바로 쓸 수 없음 → 쿠팡캐시 전환(수수료 6%, 월 50만원) → 수수료 계산·전환 화면 |
| C | CGV | 온라인 바로사용·매장 바코드·쿠폰을 단계 수와 충전 필요 여부로 비교 |
| D | 문화상품권 18자리 충전되나요? | 충전 불가 사유(발행사가 다르고 2023-01-01 제휴 종료)와 대안 |
| E | 닌텐도 / 배달의민족 | 공식 목록에 없는 곳은 ‘확인 필요’, 결과가 없으면 비슷한 이름·공식 목록·고객센터로 안내 |
| M | 문자로 받은 상품권에서 시작 | MMS의 [사용처/잔액안내] 링크로 들어오면 ‘내 상품권’이 자동으로 설정됨 |

## 화면 흐름

```
앱 홈 검색바 / 문자 상품권 링크 / 충전 완료 화면
  → [입력] 이름·카테고리·자연어 + 내 상품권 선택
  → [결과] “이렇게 이해했어요” 해석 칩 · 판정(바로 가능/바꿔서 가능/불가/확인 필요) · 온라인·매장 구분 · 출처·확인일
  → [안내] 내 상품권 기준 단계(충전 단계 자동 추가·생략) · 수수료 계산 · 방법 비교
  → [앱 화면] 시연용 문자 상품권·충전·바코드 결제·전환·쿠폰·기프트코드 → 안내로 돌아가기
```

## 구현 범위

**구현함**
- 홈 진입, 입력, 결과, 목록, 결과 없음, 사용 안내 화면
- 해석 칩 수정, 상품권 판별 도우미(상품권 번호는 받지 않음)
- 사용처 53곳(공식 154곳 중 선정), 이용 방식 7종, 카테고리 8종
- 시연용 앱 화면 6종, 진행 체크, 즐겨찾기 연동
- 규칙 기반 질문 해석기(초성·오타·조사 처리)와 자동 테스트

**구현 안 함** (컬쳐랜드 내부 검토·개발 전제)
- 실제 결제·충전·전환·로그인·본인인증
- 실제 바코드 발급, 상품권 번호(PIN) 처리
- 공식 사용처 154곳 전체·실시간 연동, LLM 해석
- 위치 기반 매장 찾기, PC 화면(설명 자료에 구상만 제시)

## 실행 방법

빌드 도구 없는 정적 사이트입니다(HTML·CSS·ES 모듈).

```bash
python tools/serve.py 8650 .
```

브라우저에서 http://localhost:8650 을 엽니다. GitHub Pages에는 저장소를 그대로 배포합니다.

### 테스트·도구

```bash
node tests/parser.test.mjs
```

| 도구 | 하는 일 |
|---|---|
| `tests/parser.test.mjs` | 질문 해석 34건, 자동완성 3건, 사용처 데이터 무결성 점검 |
| `tools/capture.py` | 설명 자료용 화면 캡처(Edge 헤드리스) |
| `tools/make_pdf.py` | 설명 자료 HTML을 PDF로 변환 |
| `tools/convert_assets.py`, `tools/extract_logo.py` | 제공받은 캐릭터 PNG를 webp로 변환하고, BI PDF에서 로고 SVG를 추출 |

## AI 활용

Claude(Anthropic)의 Claude Code를 다음 작업에 썼습니다.
- 미션 가이드 분석
- 공식 사이트 조사와 충돌 정보 재검증
- 데이터 정리
- 화면·코드·문구 작성
- 자동 테스트와 화면 점검

AI가 정리한 내용은 공식 원문과 대조해 고쳤습니다. 수정 사례는 쿠팡캐시·넥슨 한도, 카카오페이·다이소 표시, 충전 없는 문자 바코드 경로 등이고, 설명 자료 5쪽에 정리했습니다. 시제품 안에서 실시간 AI 호출은 하지 않습니다.
